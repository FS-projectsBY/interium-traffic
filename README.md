# Посещаемость ТЦ «Интериум»

Веб-программа учёта посещаемости по счётчикам входов: охрана вносит данные за день, остальные сотрудники видят отчёты и динамику.

- Сайт: https://fs-projectsby.github.io/interium-traffic/
- Данные хранятся в Firebase (проект `interium-traffic`), **в репозитории их нет**.
- Доступ — по логину и паролю; роли «Охрана», «Просмотр», «Администратор» проверяются правилами базы (`firestore.rules`).
- Первый вход администратора: адрес сайта с `?setup`, затем подтверждение почты по ссылке из письма.

Полная инструкция, тесты и исходные материалы — в рабочей папке проекта «Депхол — посещаемость\Программа 2.0».
